# Day 1 - Python & Django Setup

## Objective

Set up the Python backend development environment and install Django.

## Commands Used

python --version
pip --version
python -m venv venv
venv\Scripts\activate
pip install django
django-admin startproject config .
python manage.py runserver
python manage.py check

## Work Done

- Created a Python virtual environment.
- Activated the virtual environment.
- Verified Python and pip.
- Installed Django.
- Created the Django project.
- Started the Django development server.
- Verified the project using Django system check.

## Technologies Used

- Python
- Django
- Virtual Environment
- pip

## Outcome

The Python and Django development environment was set up successfully.
