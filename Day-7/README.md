# Day 7 - Final Task Tracker Project

## Objective

To develop and test a complete Task Tracker application using React and Django.

## Work Done

* Completed the final Task Tracker project.
* Connected React frontend with Django backend.
* Implemented Add, View, Update and Delete task operations.
* Added task validation.
* Added task search and filtering.
* Added Pending and Completed task status.
* Added task progress and task statistics.
* Added delete confirmation and error handling.
* Displayed task creation date.
* Tested the application using the JSON API.
* Verified task data in the SQLite database.

## Technologies Used

* Python

* React
* JavaScript
* Fetch API
* SQLite
* JSON
* Tailwind CSS
* Vite
* Postman
