# Day 3 - Request Handling

## Objective

Understand how Django handles different HTTP requests and returns JSON responses.

## Commands Used

python manage.py runserver
python manage.py check

## Work Done

- Implemented GET request handling.
- Implemented POST request handling.
- Implemented PUT request handling.
- Implemented DELETE request handling.
- Used JSON request data in POST and PUT requests.
- Returned JSON responses from Django views.
- Tested all requests using Postman.
- Handled unsupported HTTP methods with a 405 response.

## Technologies Used

- Python
- Django
- HTTP Methods
- JSON
- Postman

## Outcome

GET, POST, PUT, and DELETE request handling was implemented and tested successfully.
