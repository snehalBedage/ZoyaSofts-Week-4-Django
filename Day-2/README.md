# Day 2 - Django Fundamentals

## Objective

Understand Django project structure, create a Django application, and connect URLs with views.

## Commands Used

python manage.py startapp task_tracker
python manage.py check
python manage.py runserver

## Work Done

- Created the `task_tracker` Django application.
- Added the application to Django settings.
- Created URL configuration for the application.
- Connected URLs with Django views.
- Created a basic JSON response for the Task Tracker API.
- Tested the Django application in the browser.
- Verified the project using Django system check.

## Technologies Used

- Python
- Django
- Django Project
- Django Application
- URLs
- Views
- JSON Response

## Outcome

The Django project structure, application, URLs, and views were configured successfully.
