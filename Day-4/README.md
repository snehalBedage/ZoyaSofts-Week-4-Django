# Day 4 - Database Integration

## Objective

Understand Django models, migrations, and database integration using SQLite.

## Commands Used

python manage.py makemigrations
python manage.py migrate
python manage.py check
python manage.py shell

## Work Done

- Created the `Task` model.
- Added task title, description, status, and created date fields.
- Configured SQLite database for the project.
- Created database migrations.
- Applied migrations successfully.
- Created a sample task using the Django shell.
- Verified task data in the database.
- Verified the project using Django system check.
