# Day 5 - REST API

## Objective

Develop a JSON-based API for performing CRUD operations on tasks.

## Commands Used

python manage.py runserver
python manage.py check

## Work Done

- Connected the Task model with Django views.
- Implemented GET API to retrieve all tasks.
- Implemented POST API to add a new task.
- Implemented PUT API to update an existing task.
- Implemented DELETE API to delete a task.
- Used JSON request and response data.
- Stored task data in the SQLite database.
- Tested API operations using Postman.
- Verified that changes were saved correctly in the database.

## Technologies Used

- Python
- Django
- SQLite
- JSON
- REST-style API
- Postman

## Outcome

A functional JSON-based Task Tracker API with GET, POST, PUT, and DELETE operations was developed and tested successfully.
